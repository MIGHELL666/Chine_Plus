# 🎬 CineApp - Propuesta de Aplicación Móvil

[cite_start]Caso de estudio y diseño conceptual de una aplicación móvil multiplataforma orientada a los entusiastas del cine, desarrollada para la materia de **Programación Móvil**[cite: 3, 10].

## 📝 Descripción
[cite_start]Esta aplicación busca unificar en una sola plataforma la búsqueda de cines cercanos y la consulta de carteleras actualizadas[cite: 10, 17]. [cite_start]Además, incorpora un sistema inteligente de recomendaciones personalizadas basadas en el historial de películas vistas y las calificaciones de cada usuario[cite: 11, 21].

## 🚀 Características Principales
* [cite_start]**Geolocalización (GPS):** Detección automática de la ubicación del usuario para mostrar cines cercanos y ofrecer rutas[cite: 33, 54].
* [cite_start]**Cartelera Interactiva:** Consulta de películas disponibles, horarios detallados, géneros y clasificaciones[cite: 58, 59, 61, 62].
* [cite_start]**Sistema de Recomendaciones:** Análisis del historial de visualización para sugerir nuevos estrenos de interés[cite: 52, 64, 66].
* [cite_start]**Módulo de Fidelización:** Escaneo de códigos QR mediante la cámara para acumular puntos y canjearlos por productos coleccionables o descuentos[cite: 35, 36].
* [cite_start]**Notificaciones Push:** Avisos automatizados sobre estrenos, promociones y alertas de puntos por vencer[cite: 42].

## 🛠️ Tecnologías Propuestas
* [cite_start]**Frontend:** **Flutter** (para desarrollo nativo multiplataforma en Android e iOS)[cite: 75].
* [cite_start]**Backend & Base de Datos:** **Supabase** / **Firebase** (autenticación, gestión en la nube e historial de usuarios)[cite: 76, 84].
* [cite_start]**Integraciones:** **Google Maps API** (mapas y rutas) y **API de carteleras de cine**[cite: 78, 79].
